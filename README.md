Homebrew tap for tools by [harrydayexe](https://github.com/harrydayexe).

## Install

```sh
brew install harrydayexe/tap/goblog
```

Or tap first, then install by name:

```sh
brew tap harrydayexe/tap
brew install goblog
```

## Available casks

| Cask | Description |
| --- | --- |
| [`goblog`](https://github.com/harrydayexe/GoBlog) | Create a blog feed from posts written in Markdown |

`goblog` installs shell completions for bash, zsh and fish.

## Upgrade and uninstall

```sh
brew upgrade goblog
brew uninstall goblog
```

## How this tap is maintained

Casks in `Casks/` are generated and pushed by [GoReleaser](https://goreleaser.com) when a stable version of the project is released. Don't edit them by hand, because the next release will overwrite your changes. Report problems in the project's own repository instead.
